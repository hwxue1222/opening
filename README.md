# 餐厅开业筹备甘特图

一个交互式的网页甘特图，用于管理餐厅开业全流程的进度跟踪和采购管理。

## 在线预览

直接打开 `restaurant_opening_gantt.html` 文件即可使用。

## 功能特性

- **甘特图时间轴**：横轴从 8/1 到 10/1，每天一格，周末自动灰底标识
- **今天标记**：蓝色竖线标注当前日期，顶部显示距离开业倒计时
- **五色分类**：
  - 🔵 证照（蓝）
  - 🔴 装修（红）
  - 🟢 采购（绿）
  - 🟣 人员（紫）
  - ⚪ 营销（灰）
- **状态自动计算**：根据子任务完成比例自动显示「未开始 / 进行中 / 已完成」
- **子任务管理**：
  - 点击 ▶ 展开/折叠子任务
  - 点击方框勾选完成
  - 点击文字直接编辑（Enter保存，Esc取消）
  - 悬停显示 × 删除按钮
- **采购清单表格**（采购类任务专属）：
  - 名称、数量、预算、付款方式
  - 📦 出货标记（橙色）
  - ✓ 到货标记（绿色，自动勾选完成）
  - 所有字段均可点击编辑
- **详情面板**：点击任务条查看负责人、起止时间、详细说明
- **响应式设计**：支持手机、平板、电脑
- **深色模式**：自动跟随系统主题切换

## 使用方法

1. **本地使用**：双击 `restaurant_opening_gantt.html` 在浏览器中打开
2. **在线部署**：上传至任意静态托管服务（GitHub Pages、Vercel、Netlify 等）
3. **团队协作**：将文件托管在服务器上，多人可同时查看进度

## 数据修改

所有数据内嵌在HTML的 `<script>` 标签中，可直接编辑：

- **修改开业日期**：找到 `const OPENING_DATE = new Date('2026-10-01')`
- **修改任务**：找到 `let tasks = [...]` 数组
- **添加采购项**：展开采购任务，点击「+ 添加采购项」

> ⚠️ 注意：当前版本数据保存在浏览器内存中，刷新页面会恢复初始状态。如需持久化保存，建议定期将修改后的HTML源码另存为文件。

## 技术栈

- 纯 HTML + CSS + JavaScript（零依赖）
- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 使用 CSS Grid 和 Flexbox 布局
- 支持 `prefers-color-scheme` 深色模式
